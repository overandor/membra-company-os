API Documentation

CollateralOps v2.0 REST API, WebSocket, and SSE endpoints

Health & Status
GET/health
System health, version, and portfolio summary metrics.
Public
POST/api/rescan
Trigger a live rescan of local repositories. Only available in local mode.
Public
Portfolio
GET/api/balance-sheet
Full portfolio with all asset classifications and appraisals.
Public
GET/api/stats
High-level portfolio statistics and counts.
Public
GET/api/portfolio/by-type
Portfolio grouped by asset type.
Public
GET/api/portfolio/risk-blocked
Assets blocked due to risk flags.
Public
GET/api/portfolio/improvement-queue
Prioritized improvement actions across all assets.
Public
Asset Detail
GET/api/asset/{name}
Full classification and appraisal for a single asset.
Public
GET/api/asset/{name}/lender
Lender-focused risk summary.
Public
GET/api/asset/{name}/buyer
Buyer-focused acquisition summary.
Public

Public

Collateral evidence chain for an asset.
Public

Packet readiness score and checklist.
Public

Real-Time

Public

Public

Broadcast an update to all connected clients. Requires API key.

Admin
GET/api/admin/stats
Internal stats including WebSocket connection count. Requires API key via HTTP Basic password.
Auth Required
Authentication

Admin endpoints require an API key set via the COLLATERALOPS_API_KEY environment variable. Pass the key as the HTTP Basic Auth password (username can be anything).

curl -u "admin:YOUR_API_KEY" https://your-domain.com/api/admin/stats
