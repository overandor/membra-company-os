Protocol Stack

From inference to gas credit in one pipeline

Every step is cryptographically linked. No oracle, no committee.

01
Proof-of-Inference
Ed25519-signed attestation binding model CID, prompt hash, token Merkle root, KV commitment, hardware, and worker identity. Challenge window enforces contestability.
poi-core
02
Worker Trust
Every signal is gated by the worker's reputation multiplier (0–1.0×). Untrusted workers produce zero credit. Trust accrues from valid PoI and passed challenges.
worker-reputation
03
KV-State Collateral
Live transformer KV caches, prefills, attention states, and reasoning contexts become collateral. Value decays as e−3t. Reuse events reprice upward.
kv-state-collateral
04
Emergent Market Pricing
Price is a live function of retrieval frequency, downstream references, semantic cluster cohesion, and KV-layer activation density. No static appraisal.
memory-market
05
MemGas Credit → Relay → Solana
Rising market price expands the credit pool. A UserIntent with a unique nonce is validated against the spend ledger and daily cap, then lamports are authorised for the Solana relay.
memgas-protocol

Workspace Crates

Built in Rust. No external runtime.

poi-core
ProofOfInference struct, Ed25519 signing, SHA-256 KV Merkle commitment, runtime fingerprint, hardware attestation.
worker-reputation
WorkerRegistry, ReputationLedger, ChallengeSystem. Trust scoring gates all collateral and pricing signals.
kv-state-collateral
Four collateral types (KV-state, prefill, attention, reasoning context) with e−3t decay and reuse repricing.
memory-market
RetrievalTracker (24h), ReferenceGraph (48h), AttentionDensityTracker, EmergentPricingEngine with semantic clusters.
memgas-protocol
MemGasProtocol: spend ledger, nonce anti-replay, relay validation, daily wallet caps, credit deduction.
poi-network
Custom PoI consensus chain with block production and PoI-anchored finality.
poi-bridge
Solana relayer infrastructure: MemGas-authorised transaction submission bridge.
poi-cli
The poi binary. All CLI commands + the 7-step public demo console.
Public Demo Console

Seven steps. One command.

Every number is computed by the live Rust implementation — no mocks.

Step 01
Generate Inference Proof
Fresh Ed25519 keypair → PoI attestation signed by worker key. Challenge window timestamp printed.
Step 02
Register Memory
Worker trust seeded (1.00×) → memory registered → initial MemGas credit issued: 10,185 lam.
Step 03
Register KV-State Collateral
32-layer × 4096-token KV cache → 32 SHA-256 commitments → 163,840 lam collateral value.
Step 04
Simulate Retrieval & Reuse
8 cycles: retrieval + reference + attention layer activation. Live price bar grows 36K → 76K lam.
Step 05
Price Rise & Decay
5 burst rounds peak at 99,595 lam. 3 cooling steps decay to 30,074 lam. Bars shrink visibly.
Step 06
Spend MemGas Credit
UserIntent → relay validates nonce + credit + daily cap → 33,098 lam authorised for Solana tx.
Step 07
Export Proof Receipt
JSON audit receipt: worker, inference, KV-state, emergent score, MemGas. Submittable on-chain.
